# P8.3 — Design calm offline, expired-session, and empty states for Today and logging

Phase: 8 · Checkpoint A
Track: frontend
Execution: **autonomous**
Depends on: P8.2
Supersedes: OB-48

## Goal
Every degraded condition a Checkpoint A user can hit — offline, expired session, empty day — renders a calm, designed state with full snapshot evidence.

## Context and design direction
Read `_DESIGN.md` and `_RUNBOOK.md` before editing. After P8.2, Today and logging read only the
live API, so network failure and auth expiry become real user-visible conditions rather than
impossible branches. Building blocks exist: `TodayLoadingStateView` / `TodayErrorStateView`
(referenced in `RootPlaceholderView.swift`), the central 401 handling from P4.4, and the
expired-session UX from P5.8 (mid-session 401 → calm return to sign-in, re-auth lands back in
context). This ticket completes the roadmap's state matrix for Today + logging: offline/unreachable,
expired-session, and empty (a fresh account's day with zero entries — distinct from the goal-less
state P6.2 designed). Savoro's voice is calm and non-judgmental; banned copy (failure, failed,
over limit, guilt, jargon, raw IDs) is a landing blocker. This ticket is deliberately scoped so
another fresh agent can verify and land it independently.

## Files
- `SavoroIOS/Savoro/Features/Today/` (offline, empty-day, retry states)
- `SavoroIOS/Savoro/Features/Logging/` (form/list degraded states: submit-while-offline, retry)
- `SavoroIOS/Savoro/App/RootPlaceholderView.swift` (only where these states are routed)
- `SavoroIOS/SavoroTests/` (state unit tests + snapshot matrix additions)
- `SavoroIOS/Scripts/record-snapshots.sh` (grow the pinned reference count deliberately)

This fence is degraded-state presentation and routing; the 401 plumbing (P4.4/P5.8) and live
wiring (P8.2) are landed dependencies — reuse, don't rebuild.

## Approach
1. Enumerate the state matrix per surface and write it into the tests first:
   - Today: loading, loaded, empty day (zero entries, with and without a goal), offline/error
     with retry, expired-session handoff;
   - manual logging (P8.1 form): validation, submit error (offline), expired-session handoff.
2. Build each state from L-35 primitives with copy in Savoro's voice — e.g. offline says what is
   temporarily unavailable and offers retry; it never says "failed" or blames anyone.
3. Expired session routes through the P5.8 flow — do not add a second 401 path; verify re-auth
   returns to the interrupted surface.
4. Distinguish empty from error visibly: an empty day is a normal, welcoming state (this is every
   fresh Checkpoint A user's first screen), not a warning.
5. Snapshot every named state in {light,dark} × {standard,XXXL}; grow the pinned count in
   `record-snapshots.sh` in this ticket only.
6. Unit-test the state selection logic (which state renders for which loader/API outcome) and run
   the banned-copy grep over all new strings.

## Done when
- Every cell of the state matrix above has a rendering, a unit test selecting it, and four
  snapshot modes committed.
- Offline Today offers retry and recovers to loaded when the API returns (test via a stubbed
  client that fails then succeeds).
- Expired-session UX reuses P5.8's path; no data loss on re-auth (assert the in-progress manual
  form survives or is honestly explained).
- Banned-copy grep is clean over all new visible strings; no raw IDs or backend jargon.
- Full iOS suite green; pinned snapshot count grown only here.

## Watch out
- Do not re-record any existing reference outside this ticket's new states; the pinned count grows
  deliberately, never silently (never-weaken-a-gate).
- The goal-less state is P6.2's, already designed and reviewed at P7.3 — do not restyle it here;
  empty-day and goal-less can co-occur, so test that combination without redesigning either.
- No fixture data may back these states at runtime (P8.2's guard will catch it); previews/tests
  inject stubs explicitly.
- If the roadmap state matrix conflicts with compiled reality (e.g. P5.8 shipped a different
  re-auth return path), follow the code and note the delta; if it conflicts with a locked
  decision, mark **blocked** with evidence.
- XXXL is where degraded states usually clip — check the retry affordance at ≥44pt and single-line
  pills at accessibility sizes before calling it done.
